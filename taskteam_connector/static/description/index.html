TaskTeam Connector

Give TaskTeam read access to your employees, companies and contacts in one click, with a dedicated user and an API key that you control.

TaskTeam is an external service. TaskTeam is a task and chat app for field teams, run by Task Team Tech, S.L. You need a TaskTeam account to use this module. The module only prepares access inside your Odoo: it does not send any data anywhere by itself. TaskTeam reads your data only after you paste the key into TaskTeam.

What the module does

An administrator opens Settings › TaskTeam, ticks the consent box and clicks Connect TaskTeam. The module then creates:

  • an internal user TaskTeam (login taskteam, no password, no invitation email) with minimal rights: Internal User and Employees › Officer, limited to the companies you select;
  • an API key for that user, shown only once. On Odoo 17 API keys do not expire: the key stays valid until you revoke it.

Running it again creates a new key without duplicating the user. Disconnect revokes all keys of the TaskTeam user and archives it.

What TaskTeam reads

TaskTeam reads, read-only, through Odoo's external API:

  • Employees: name, company, job position, work phone and mobile, work email and, when the TaskTeam user may read it in Odoo, the identification number;
  • Companies: the companies you select;
  • Customers and suppliers: contacts marked as customer or supplier;

You stay the owner of your data. You can revoke access at any time from Settings › TaskTeam › Disconnect or from the user's API keys.

Setup

  1. Install the module (it depends only on base and Employees).
  2. Go to Settings › TaskTeam.
  3. Select the companies TaskTeam may read, tick the consent box and click Connect TaskTeam. Odoo may ask for your password.
  4. Copy the key and your Odoo address and paste them in TaskTeam › Perfil › Conexiones › Odoo.
  5. To replace the key, open Settings › TaskTeam again, click Create a new key and revoke the old one from the TaskTeam user's API keys.

Requirements

  • A TaskTeam account.
  • An Odoo database where you can install modules and use the external API (Odoo.sh or on-premise).
