TaskTeam Connector

Give TaskTeam access to your employees, companies and contacts and, if you allow it, let it create draft sale orders from signed delivery notes. One click, with a dedicated user and an API key that you control.

TaskTeam is an external service. TaskTeam is a task and chat app for field teams, run by Task Team Tech, S.L. You need a TaskTeam account to use this module. The module only prepares access inside your Odoo: it does not send any data anywhere by itself. TaskTeam can use your Odoo only after you paste the key into TaskTeam.

What the module does

An administrator opens Settings › TaskTeam, ticks the consent box and clicks Connect TaskTeam. The module then creates:

  • a group TaskTeam API that allows API keys valid for up to 1 year (reused if it already exists);
  • an internal user TaskTeam (login taskteam, no password, no invitation email) with minimal rights: Internal User and Employees › Officer, limited to the companies you select and, only if you tick it and Sales is installed, Sales › User: Own Documents Only;
  • an API key for that user, valid for 365 days and shown only once.

Running it again creates a new key without duplicating the user or the group. Disconnect revokes all keys of the TaskTeam user and archives it.

What TaskTeam does

Through Odoo's external API, with that user's rights only, TaskTeam reads:

  • Employees: name, company, job position, work phone and mobile, work email and, when the TaskTeam user may read it in Odoo, the identification number;
  • Companies: the companies you select;
  • Customers and suppliers: contacts marked as customer or supplier;
  • The key itself: its expiry date, to remind you to renew it.

Draft sale orders (only if you allow it, and only when the Sales app is installed): TaskTeam creates sale orders in draft with the signed delivery note PDF attached, for your office to review and invoice. It never confirms, changes or deletes anything. Untick the option and create a new key to take this permission away.

You stay the owner of your data. You can revoke access at any time from Settings › TaskTeam › Disconnect or from the user's API keys.

Setup

  1. Install the module (it depends only on base and Employees).
  2. Go to Settings › TaskTeam.
  3. Select the companies TaskTeam may read, tick the consent box and click Connect TaskTeam. Odoo may ask for your password.
  4. Copy the key and your Odoo address and paste them in TaskTeam › Perfil › Conexiones › Odoo.
  5. Before the key expires (365 days), open Settings › TaskTeam again and click Create a new key.

Requirements

  • A TaskTeam account.
  • An Odoo database where you can install modules and use the external API (Odoo.sh or on-premise).
